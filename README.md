# fate-st-maker

Lostbelt 타이틀 카드(16:9)를 브라우저에서 만들고 PNG/JPG로 내려받는 프론트엔드 전용 도구입니다.
React + styled-components + Vite.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성 (base: './' 라 아무 경로에나 올려도 동작)
```

## 페이지 경로

메이커마다 하위 경로를 하나씩 씁니다. 이 메이커는 `/lostbelt/` 이고, 루트(`/`)는 메이커 목록입니다.
새 메이커를 추가할 때는 `새이름/index.html` 을 만들고 `vite.config.js` 의 `build.rollupOptions.input` 에 넣으면 되며,
기존 페이지 주소는 바뀌지 않습니다. 개발 서버에서는 `http://localhost:5173/lostbelt/` 로 엽니다.

## 화면 구성

- 각 부분의 **표시 여부**는 파트 이름 오른쪽 끝의 스위치로 켜고 끕니다. **폰트·굵기**와 **채우기**(그라데이션 편집기)는 고급 설정에 있습니다.
- 배경: 메인은 이미지와 크기·위치, 고급 설정은 사진 스타일 변환(방식·톤 색)과 분위기(밝기·흰색 덮기·눈 입자). 보정 필터·비네트·중앙 광원·눈 입자 개수 등은 고정값입니다.
- 콘솔에는 자주 바꾸는 항목만 있습니다. 텍스트의 크기·위치, 상단선·하단선, 글자(기울임·자간·장평)·외곽선·그림자·글로우 불투명도, 로고의 배치·불투명도·가장자리 색·뒤쪽 그림자·색 입히기, 렌즈 플레어의 모양(합성·길이·두께 등) 같은 값은 고정값이며 `src/card/defaults.json`(없으면 `defaults.js`)에서 바꿉니다.
- 로고를 ‘직접 업로드’로 두고 이미지를 올리지 않으면 로고는 그려지지 않습니다 (기본 이미지 없음).

- 오른쪽 콘솔 위쪽의 **카드 구조도**는 실제 렌더링 위치를 축소해 각 부분을 블록으로 보여줍니다.
  블록이나 아래 탭, 또는 미리보기 캔버스에서 해당 부분을 누르면 그 부분의 설정만 표시됩니다.
- 콘솔은 위에서부터 **테마 색** → **카드 구조도(바꿀 부분 고르기)** → 고른 부분의 설정 순서입니다.
- **테마 색**: 오른쪽 위 색 견본에서 대표색(제목 위쪽 색)을 고르면, 그때만 바뀔 색의 ‘지금 → 적용 후’ 견본과 **이 색으로 바꾸기** 버튼이 나타납니다. 고르는 동안(색 선택기에서 끄는 중에도) 미리보기 캔버스에 결과가 바로 보이며, 적용 전에는 설정이 바뀌지 않습니다 (**취소** 로 원래대로). **초기 색으로**는 항상, **되돌리기**는 적용 직후에 보입니다.
- 다운로드는 미리보기 바로 아래에서 합니다. 정지 이미지 / 인트로 / 아웃트로마다 형식·해상도(애니메이션은 프레임 수도)를 따로 고릅니다.
- 설정은 **메인 설정**(텍스트, 폰트, 크기, 위치, 색)과 접을 수 있는 **고급 설정**(자간, 외곽선, 글로우, 그림자 등)으로 나뉩니다.

## 그라데이션 편집기

글자(왼쪽 위·오른쪽 위·연대·제목·부제), 구분선, 아웃트로 문구의 색은 피그마처럼 한 곳에서 편집합니다 (`src/components/fields/GradientEditor.jsx`).

- 형태: 단색 / 가로 그라데이션 / 세로 그라데이션 (구분선은 단색·가로, 아웃트로 문구는 세로)
- 띠 위의 핀을 끌어 위치 조정, 띠의 빈 곳을 누르면 그 위치의 색으로 지점 추가, 핀 선택 후 ←→ 로 1%씩 이동·Delete 로 삭제
- 아래 목록에서 위치(%)·색(색상 선택기 또는 #코드) 입력, − 로 삭제 (최소 2개), ⇆ 방향 뒤집기
- **◇ 대칭화** 켜기/끄기: 켜면 절반(끝 → 가운데 50%)만 입력하고 나머지 절반은 거울처럼 자동으로 채워짐 (띠에는 빗금 친 “자동 대칭” 영역과 흐린 핀으로 보이지만 고르거나 끌 수 없음). 켤 때는 지금의 앞쪽 절반을 기준으로 다시 만들고, 끄면 지금 모양 그대로 전체를 자유 편집 (원본처럼 대칭인 제목·연대·왼쪽 위·부제·구분선은 기본으로 켜짐)
- 값은 `stops: [[위치 0~1, 색], ...]` 로 저장. 예전의 색 1·색 2·가운데 폭 설정은 불러올 때 자동으로 지점 목록으로 바뀝니다
- 테마 색은 각 지점의 밝기를 유지한 채 색조만 대표색으로 바꿉니다 (배경 톤 색 두 개도 같은 방식으로 함께 바뀌며, 업로드 사진뿐 아니라 기본 설산 배경에도 적용)

## 배경 직접 조정

배경 패널의 **화면에서 끌어서 조정하기**(정지 이미지 모드)를 누르면 사진 편집 툴처럼 조정할 수 있습니다.

- 사진 안쪽을 끌면 이동, 네 모서리 손잡이를 끌면 반대쪽 모서리를 고정한 채 확대·축소 (100~300%)
- 카드 밖으로 넘쳐 잘리는 부분은 카드 뒤에 흐리게 보이고, 미리보기는 사진 전체가 보이도록 잠시 줄어듦
- **적용**(Enter)을 눌러야 확대·가로 위치·세로 위치 값이 반영되고, **취소**(Esc)하면 원래대로 (`src/components/BgEditor.jsx`)

## 배경 사진 스타일 변환

배경에 일반 사진을 올리면 **사진 스타일 변환**이 적용되어 예시 이미지 같은 설원 일러스트 톤이 됩니다
(밝기만 뽑아 노출·대비를 조정한 뒤 어두운 색~밝은 색 두 색으로 다시 칠함).

- 듀오톤 (기본) / 2치화 / 원본 그대로 — 톤 색(어두운 부분·밝은 부분)은 배경 메인 설정에서 지정
- 고급 설정에서 밝기, 대비, 단계 수, 2치화 기준과 경계, 잡티 줄이기, 어두운·밝은 부분 색을 조절
- 변환 결과는 이미지·설정별로 캐시되어 애니메이션 재생에도 부담이 없음

## 임시 로고 생성 (연대·제목 → 패턴 문장)

로고 패널 맨 위의 선택 막대에서 **직접 업로드 / 연대·제목으로 자동 생성** 중 하나를 고릅니다.
자동 생성을 고르면 형태(외곽선 아이콘 버튼), 분할 수, 채움 비율, 조각 사이 간격, 테두리, 색 옵션이 나타나고,
연대·제목이나 옵션을 바꿀 때마다 GitHub 기본 프로필(identicon)처럼 좌우대칭 패턴 문장이 바로 다시 만들어집니다.
생성형 AI가 아니라 정해진 계산이라, 같은 문자열 + 같은 옵션이면 항상 같은 결과가 나옵니다 (`src/card/logoGen.js`).
직접 업로드로 돌아가면 올려 둔 이미지(없으면 기본 로고)가 다시 쓰입니다.

형태마다 어울리는 하위 요소로 실루엣을 쪼개고, 해시가 각 하위 요소를 칠할지 정합니다.

| 형태 | 하위 요소 (분할 수 N 의 의미) |
|---|---|
| 사각형 | N×N 작은 정사각형 격자 (GitHub 방식) |
| 원형 | 극좌표 — 가운데 원판 + 동심원 고리 ⌈N/2⌉개, 고리마다 바깥일수록 많은 호 조각 |
| 마름모 | 45도 돌린 N×N 격자 — 작은 마름모 |
| 삼각형 | N줄 삼각형 메시 — 위·아래 방향 작은 삼각형이 번갈아 (줄마다 2개씩 늘어남) |
| 육각형 | 벌집 — 반지름 ⌊N/2⌋ 의 작은 육각형 무리 |
| 방패 | N×N 격자를 방패 외곽선으로 잘라냄 |

1. 입력 문자열 = `연대 + "\u0000" + 제목`
2. cyrb53 해시(53비트)의 하위 32비트를 시드로 mulberry32 난수열 생성
3. 형태별 분할로 하위 요소를 만들고, 좌우대칭 쌍(또는 세로축 위 단독 요소)으로 묶어 정해진 순서로 나열
4. 나열 순서대로 쌍마다 난수를 하나씩 뽑아 난수 < 채움 비율이면 쌍을 함께 칠함 → 좌우대칭
5. 칠한 요소가 전체의 25% 미만이면 세로축 위 요소를 모두 칠함
6. 간격만큼 각 요소를 자기 중심 쪽으로 줄이고, 테두리를 켜면 실루엣 외곽선을 그림 → 투명 배경 PNG(640×640)

## 렌즈 플레어

로고와 제목 오른쪽 위에 가로로 늘인 렌즈 플레어가 있습니다. 각각 로고 패널·제목 패널 메인의 **렌즈 플레어** 로 켜고 끄며, 고급 설정에서 색·합성 방식·위치(로고 기준 / 제목 영역 오른쪽 위 모서리 기준)·길이·두께·강도를 조절합니다. 인트로에서는 밝아진 뒤 깜빡이고, 어두워졌을 때와 아웃트로에서는 나타나지 않습니다. 테마 색을 바꾸면 두 플레어 색도 함께 바뀝니다.


## 애니메이션 (인트로 / 아웃트로)

미리보기 위의 전환 버튼에서 **정지 이미지 · 인트로 · 아웃트로** 를 고릅니다.
현재 카드 설정을 그대로 사용해 애니메이션을 만들고, 재생 막대로 확인한 뒤 MP4 또는 GIF 로 내려받습니다.

- **인트로**: 어두워진 화면 (네 귀퉁이가 검은 원형 비네트, 배경은 흐리고 살짝 확대) → 상단 선이 빛나며 그려짐 → 왼쪽 위·오른쪽 위 텍스트가 상단 선 아래에서 동시에 올라옴 (오른쪽 위는 ‘_ 앞 / _ 뒤’ 두 칸으로 따로 입력하며, `_` 뒤 칸의 글자는 자리만 차지하다가 로고와 함께 나타남 — 각 칸에 `_` 가 들어가도 됨) → 상단 선 위로 입자가 떠오름 → 로고가 살짝 확대된 상태에서 줄어들며 흰 실루엣으로 등장 (`_` 뒤 글자도 함께) → 중앙에서 원형으로 넓어지며 밝아짐 (비네트·흐림 해제), 연대·제목 페이드 인, 렌즈 플레어 깜빡임 → 다 밝아진 뒤 하단 선 + 부제 페이드 인, 하단 선 위로 입자 → 아래에서 회로 무늬 띠가 올라감 (넉넉한 간격의 세로선이 45도 대각선으로 옆 줄과 이어지는 기판 배선 모양), 배경은 끝까지 천천히 축소
  - 떠오르는 입자와 회로 무늬는 ‘입자 시드’ 값으로 배치가 정해지며, 시드를 바꾸면 다른 배치가 나옵니다
- **아웃트로**: 로고 중심에서 어둠이 번짐 → 로고가 흰빛으로 빛남 → 로고 아래 중심에서 노란 섬광 (섬광·광선이 사라지고 로고가 검게 되는 것은 ‘공상절제’ 가 다 나타나는 시점에 함께 끝남) → 양옆에서 정방형 입자가 터져 나옴 + ‘공상절제’ 페이드 인 시작 + 육각형 윤곽선 회로 무늬(위·아래 두 줄로 화면 맨 위까지 덮음)가 아래에서 반짝이며 올라옴 → ‘공상절제 / Cosmos Denial’ 이 중앙에서 퍼지듯 등장, 정방형 입자는 서로 다른 속도로 작아지며 위로 올라가고 화면 위에서 금빛 입자가 쏟아져 내림 → 입자가 모두 사라지면 중앙부터 완전히 어두워짐
- 파일은 프레임 단위로 렌더링하므로 재생 성능과 무관하게 정확한 프레임으로 저장됩니다.
  - MP4: WebCodecs + [Mediabunny](https://mediabunny.dev/) (H.264 우선, 안 되면 VP9/AV1). 최신 Chrome·Edge·Safari 필요, https 또는 localhost 에서만 동작
  - GIF: [gifenc](https://github.com/mattdesl/gifenc) (프레임마다 256색 팔레트)
- 회로 무늬는 직접 그린 이미지로 바꿀 수 있습니다 (애니메이션 패널 → 고급 설정 → 회로 무늬 이미지, 인트로/아웃트로 각각)
  - 1920×1080 (또는 3840×2160) **투명 배경 PNG**, 선은 아무 색이나 불투명하게 (색·불투명도는 앱에서 다시 입힘)
  - 선 두께는 1080 기준 2~3px, 화면 전체를 고르게 채우되 가운데(문구 자리)는 조금 비워 두면 좋음
- 화면 상태 이름: 원래 카드 상태는 **밝아졌을 때**, 인트로 시작·아웃트로처럼 어두운 상태는 **어두워졌을 때** 로 부릅니다
  - **밝아졌을 때의 요소 조정 (안개·비네트)**: 배경 패널 → 고급 설정
  - **어두워졌을 때의 요소 조정 (안개)**: 애니메이션 패널 메인 — 자욱한 정도(덮는 면적)·진하기·덩어리 크기·색, 자욱한 정도나 진하기가 0이면 끔
  - **어두워졌을 때의 요소 조정 (비네트·색조·배경)**: 애니메이션 패널 → 고급 설정 — 어두워짐·밝아짐 전환 모양(가로 / 세로 비율, 기본 1.35 = 가로로 조금 넓은 타원, 1 = 원), 배경 비네트, 인트로 네 귀퉁이 비네트, 색조, 인트로 배경 확대·흐림, 아웃트로 로고 색
- 어두워졌을 때는 구름·안개 노이즈가 천천히 흐릅니다
- **움직임 곡선 · 재생 시간** (애니메이션 패널 → 고급 설정): 단계마다 움직임 곡선과 시작·끝 시간(초, 재생 속도 1배 기준)을 정하고, 전체 길이 안에서의 위치를 막대로 보여줍니다. 값은 `anim.times` 에 저장되며 단계 목록은 `src/card/animation/timing.js`
  - 전체 길이는 단계 시간에 맞춰 자동으로 늘거나 줄어듭니다 (인트로: 모든 단계(입자·회로 무늬 포함)가 끝난 뒤 + ‘끝난 뒤 마지막 화면 유지’ 시간 — 이 동안은 마지막 화면이 그대로 멈춰 있음, 아웃트로: 문구가 다 나타난 뒤 + 유지 시간 + 마지막 어두워짐 길이)
  - 아웃트로의 ‘섬광·로고 어두워짐을 문구가 다 나타날 때 함께 끝내기’ 를 켜면 두 단계의 끝이 문구 페이드 인 끝을 따라갑니다 (기본 켜짐)
- ‘공상절제 / Cosmos Denial’ 문구는 빛 입자보다 위에 그려집니다
- 정방형 입자는 터지기 직전 짧게 등장합니다 (확대 + 페이드 인, `defaults.json` 의 diamondIn* 값)
- 입자 크기·색, 아웃트로 제목 색·글로우 등은 고정값입니다 (`defaults.json`)
- 문구, 폰트, 유지 시간, 속도, 색, 입자 양 등은 ‘애니메이션’ 패널에서 바꿉니다.

```
src/card/animation/
  index.js     애니메이션 목록 (길이, 프레임 그리기)
  timing.js    단계별 재생 시간 표 (기본값, 콘솔 항목)
  intro.js     인트로 타임라인
  outro.js     아웃트로 타임라인
  night.js     어두워졌을 때의 카드 (원래 설정에서 색·밝기만 바꾼 버전)
  effects.js   라인 빛, 안개 노이즈, 잉크 번짐, 원형 밝아짐, 별 섬광, 정방형·금빛·떠오르는 입자, 회로 무늬
src/lib/videoExport.js   MP4 / GIF 만들기
```

## 폰트 선택지

부분마다 고를 수 있는 폰트가 정해져 있고(폰트와 굵기를 함께 고름, 첫 번째가 기본값), 각 폰트 칸의 **업로드**로 직접 올린 폰트를 그 목록에 추가할 수 있습니다 (`src/card/fonts.js` 의 `FONT_GROUPS`).

| 부분 | 선택지 | 업로드 칸 |
|---|---|---|
| 왼쪽 위 (Lostbelt No.1) | Spectral 700 (기본), Cormorant Garamond 700, Bodoni Moda 600 | 왼쪽 위 폰트 |
| 연대 (A.D.1570?), 아웃트로 영문 부제 (Cosmos Denial) | Libre Bodoni 400 (기본), Old Standard TT 700, Playfair Display 600 | 영문 폰트 (두 곳이 함께 씀) |
| 한글 (오른쪽 위, 제목, 부제, 공상절제 문구) | 함초롬바탕, Noto Sans/Serif KR, 나눔고딕·명조, 검은고딕, 도현, 고운바탕 — 굵기는 따로 | 한글 폰트 |

폰트를 고르면 그 선택지의 기본 굵기로 바뀌고, 아래 **굵기** 칸에서 다시 바꿀 수 있습니다. 굵기를 바꾸면 그 선택지의 기본 굵기도 함께 바뀌어(설정의 `fontWeights`) 다른 폰트로 갔다 와도 유지되고, **설정 저장** 파일에도 포함됩니다. 굵기 칸에는 그 폰트가 실제로 가진 굵기만 나옵니다.

업로드한 폰트는 지금 탭에서만 유지됩니다 (새로고침하면 다시 올려야 하고, 저장된 설정의 그 폰트는 기본값으로 돌아감).

## 함초롬바탕

제목·부제 기본 폰트는 함초롬바탕(HCR Batang)입니다. 한컴 저작권 폰트라 레포에 포함하지 않았고, 다음 순서로 찾습니다.

1. 기기에 설치된 폰트 (한컴오피스 설치 시 포함)
2. 눈누 CDN(jsDelivr)의 함초롬바탕 — `https://cdn.jsdelivr.net/gh/projectnoonnu/noonfonts_2104@1.0/HANBatang.woff`, `HANBatangB.woff` (굵게)
3. 한글 폰트 칸의 ‘업로드’로 올린 파일 (파일 이름에 HCR/함초롬이 들어 있으면 자동으로 함초롬바탕으로 등록)

셋 다 없으면 Noto Serif KR 로 대신 그립니다.

## 기본값 바꾸기

기본값은 두 겹입니다.

- `src/card/defaults.js` — 코드에 적은 기본값 (항목 목록과 자료형의 기준)
- `src/card/defaults.json` — 실제로 쓰는 기본값. 여기 있는 값이 위 값보다 우선하며, 없는 항목은 코드 기본값을 씁니다

툴바의 **설정 저장** 으로 받은 JSON 의 `settings` 부분으로 `defaults.json` 을 바꾸고 다시 빌드하면 새 기본값이 됩니다. 콘솔에서 뺀 고정값(크기·위치·선·재생 속도 등)도 이 파일에서 바꿉니다.

## 커스텀 항목 추가하기

1. `src/card/defaults.js` 의 해당 섹션에 기본값을 추가
2. `src/card/schema.js` 의 해당 파트 `main` 또는 `advanced` 에 컨트롤을 추가 (UI는 자동 생성, `when` 으로 조건부 표시 가능)
3. `src/card/renderer.js` 에서 그 값을 사용

위치·크기 값은 모두 카드 크기 대비 비율입니다. 가로 관련은 `%W`, 세로·폰트 크기·번짐은 `%H` 입니다.
그래서 해상도를 바꿔도 배치가 같습니다.
