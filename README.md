# fate-st-maker

Lostbelt 타이틀 카드(16:9)를 브라우저에서 만들고 PNG/JPG로 내려받는 프론트엔드 전용 도구입니다.
React + styled-components + Vite.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 파일 생성 (base: './' 라 아무 경로에나 올려도 동작)
```

## 화면 구성

- 오른쪽 콘솔 위쪽의 **카드 구조도**는 실제 렌더링 위치를 축소해 각 부분을 블록으로 보여줍니다.
  블록이나 아래 탭, 또는 미리보기 캔버스에서 해당 부분을 누르면 그 부분의 설정만 표시됩니다.
- 설정은 **메인 설정**(텍스트, 폰트, 크기, 위치, 색)과 접을 수 있는 **고급 설정**(자간, 외곽선, 글로우, 그림자 등)으로 나뉩니다.

## 배경 사진 스타일 변환

배경에 일반 사진을 올리면 **사진 스타일 변환**이 적용되어 예시 이미지 같은 설원 일러스트 톤이 됩니다
(밝기만 뽑아 노출·대비를 조정한 뒤 어두운 색~밝은 색 두 색으로 다시 칠함).

- 듀오톤 (기본) / 단계 분리 / 2치화 / 원본 그대로 — 톤 색(어두운 부분·밝은 부분)은 배경 메인 설정에서 지정
- 고급 설정에서 밝기, 대비, 단계 수, 2치화 기준과 경계, 잡티 줄이기, 어두운·밝은 부분 색을 조절
- 변환 결과는 이미지·설정별로 캐시되어 애니메이션 재생에도 부담이 없음

## 임시 로고 생성 (연대·제목 → 패턴 문장)

로고 패널의 **임시 로고 만들기**에서 형태, 분할 수, 채움 비율, 조각 사이 간격, 테두리, 색을 고르고
**연대·제목으로 로고 생성하기**를 누르면 GitHub 기본 프로필(identicon)처럼 좌우대칭 패턴 문장이 만들어져 로고로 들어갑니다.
같은 문자열 + 같은 옵션이면 항상 같은 결과가 나옵니다 (`src/card/logoGen.js`).

형태마다 어울리는 하위 요소로 실루엣을 쪼개고, 해시가 각 하위 요소를 칠할지 정합니다.

| 형태 | 하위 요소 (분할 수 N 의 의미) |
|---|---|
| 사각형 | N×N 작은 정사각형 격자 (GitHub 방식) |
| 원형 | 극좌표 — 가운데 원판 + 동심원 고리 ⌈N/2⌉개, 고리마다 바깥일수록 많은 호 조각 |
| 마름모 | 45도 돌린 N×N 격자 — 작은 마름모 |
| 삼각형 | N줄 삼각형 메시 — 위·아래 방향 작은 삼각형이 번갈아 (줄마다 2개씩 늘어남) |
| 육각형 | 벌집 — 반지름 ⌊N/2⌋ 의 작은 육각형 무리 |
| 방패 | N×N 격자를 방패 외곽선으로 잘라냄 |

1. 입력 문자열 = `연대 + "\u0000" + 제목`
2. cyrb53 해시(53비트)의 하위 32비트를 시드로 mulberry32 난수열 생성
3. 형태별 분할로 하위 요소를 만들고, 좌우대칭 쌍(또는 세로축 위 단독 요소)으로 묶어 정해진 순서로 나열
4. 나열 순서대로 쌍마다 난수를 하나씩 뽑아 난수 < 채움 비율이면 쌍을 함께 칠함 → 좌우대칭
5. 칠한 요소가 전체의 25% 미만이면 세로축 위 요소를 모두 칠함
6. 간격만큼 각 요소를 자기 중심 쪽으로 줄이고, 테두리를 켜면 실루엣 외곽선을 그림 → 투명 배경 PNG(640×640)

## 원본 겹쳐보기

툴바의 **원본 겹쳐보기**를 켜면 참고용 원본 캡처를 미리보기 위에 반투명하게 겹쳐 위치와 폰트를 비교할 수 있습니다.
`public/reference/` 의 이미지(모두 검은 띠를 잘라 1920×1080 으로 맞춤) 중에서 고르며, ‘자동’은 모드에 맞는 것을 씁니다.

- 정지 카드 (`lostbelt-no1.jpg`)
- 아웃트로 · 섬광 (`outro-flash.jpg`, 약 2.8초 시점)
- 아웃트로 · 문구 (`outro-text.jpg`, 문구가 다 나타난 뒤)

애니메이션 모드에서는 재생 막대로 같은 시점에 맞춘 뒤 비교하세요. 불투명도 조절, **차이** 모드(정확히 겹치는 부분이 검게 보임)를 지원하며
다운로드 파일에는 포함되지 않습니다.

## 애니메이션 (인트로 / 아웃트로 · 공상절제)

미리보기 위의 전환 버튼에서 **정지 이미지 · 인트로 · 아웃트로(공상절제)** 를 고릅니다.
현재 카드 설정을 그대로 사용해 애니메이션을 만들고, 재생 막대로 확인한 뒤 MP4 또는 GIF 로 내려받습니다.

- **인트로**: 어두운 장면 (네 귀퉁이가 검은 원형 비네트, 배경은 흐리고 살짝 확대) → 상단 선이 빛나며 그려짐 → 왼쪽 위·오른쪽 위 텍스트가 상단 선 아래에서 동시에 올라옴 (오른쪽 위의 `_` 뒤 글자는 자리만 차지) → 상단 선 위로 입자가 떠오름 → 로고가 살짝 확대된 상태에서 줄어들며 흰 실루엣으로 등장 (`_` 뒤 글자도 함께) → 중앙에서 원형으로 넓어지며 밝아짐 (비네트·흐림 해제), 연대·제목 페이드 인, 렌즈 플레어 깜빡임 → 다 밝아진 뒤 하단 선 + 부제 페이드 인, 하단 선 위로 입자 → 아래에서 회로 무늬 띠가 올라감, 배경은 끝까지 천천히 축소
  - 떠오르는 입자와 회로 무늬는 ‘입자 시드’ 값으로 배치가 정해지며, 시드를 바꾸면 다른 배치가 나옵니다
- **아웃트로**: 로고 중심에서 어둠이 번짐 → 로고가 흰빛으로 빛남 → 로고 아래 중심에서 노란 섬광 → 양옆에서 정방형 입자가 터져 나옴 + ‘공상절제’ 페이드 인 시작 + 108도 회로 무늬가 아래에서 반짝이며 올라옴 → ‘공상절제 / Cosmos Denial’ 이 중앙에서 퍼지듯 등장, 정방형 입자는 서로 다른 속도로 작아지며 위로 올라가고 화면 위에서 금빛 입자가 쏟아져 내림 → 입자가 모두 사라지면 중앙부터 암전
- 파일은 프레임 단위로 렌더링하므로 재생 성능과 무관하게 정확한 프레임으로 저장됩니다.
  - MP4: WebCodecs + [Mediabunny](https://mediabunny.dev/) (H.264 우선, 안 되면 VP9/AV1). 최신 Chrome·Edge·Safari 필요, https 또는 localhost 에서만 동작
  - GIF: [gifenc](https://github.com/mattdesl/gifenc) (프레임마다 256색 팔레트)
- 회로 무늬는 직접 그린 이미지로 바꿀 수 있습니다 (애니메이션 패널 → 고급 설정 → 회로 무늬 이미지, 인트로/아웃트로 각각)
  - 1920×1080 (또는 3840×2160) **투명 배경 PNG**, 선은 아무 색이나 불투명하게 (색·불투명도는 앱에서 다시 입힘)
  - 선 두께는 1080 기준 2~3px, 화면 전체를 고르게 채우되 가운데(문구 자리)는 조금 비워 두면 좋음
- 문구, 폰트, 유지 시간, 속도, 색, 입자 양 등은 ‘애니메이션’ 패널에서 바꿉니다.

```
  intro.js     인트로 타임라인
  outro.js     아웃트로(공상절제) 타임라인
  night.js     밤 장면 (원래 설정에서 색만 바꾼 버전)
  effects.js   라인 빛, 잉크 번짐, 원형 밝아짐, 별 섬광, 정방형·금빛·떠오르는 입자, 회로 무늬
src/lib/videoExport.js   MP4 / GIF 만들기
```

## 함초롬바탕

제목·부제 기본 폰트는 함초롬바탕(HCR Batang)입니다. 한컴 저작권 폰트라 레포에 포함하지 않았고, 다음 순서로 찾습니다.

1. 기기에 설치된 폰트 (한컴오피스 설치 시 포함)
2. `public/fonts/HCRBatang.woff2`, `public/fonts/HCRBatang-Bold.woff2` (라이선스를 확인한 뒤 직접 넣기)
3. 툴바의 ‘폰트 추가’로 올린 파일 (파일 이름에 HCR/함초롬이 들어 있으면 자동으로 함초롬바탕으로 등록)

셋 다 없으면 Noto Serif KR 로 대신 그립니다.

## 커스텀 항목 추가하기

1. `src/card/defaults.js` 의 해당 섹션에 기본값을 추가
2. `src/card/schema.js` 의 해당 파트 `main` 또는 `advanced` 에 컨트롤을 추가 (UI는 자동 생성, `when` 으로 조건부 표시 가능)
3. `src/card/renderer.js` 에서 그 값을 사용

위치·크기 값은 모두 카드 크기 대비 비율입니다. 가로 관련은 `%W`, 세로·폰트 크기·번짐은 `%H` 입니다.
그래서 해상도를 바꿔도 배치가 같습니다.

## 원본 효과 분석

| 요소 | 효과 |
|---|---|
| 배경 | 밝기↑ 대비↓ 채도↓, 흰색 워시, 흰 비네트, 하단 안개, 로고 뒤 방사형 광원, 눈 입자 |
| 왼쪽 위 | 굵은 영문 세리프, 남색 세로 그라데이션, 흰 글로우 |
| 오른쪽 위 | 가는 회색 고딕, 흰 글로우, 오른쪽 정렬 |
| 구분선 | 얇은 회색 선, 양 끝 페이드 |
| 로고 | 짙은 실루엣, 흰 외곽 광채, 푸른 가로 렌즈 플레어 |
| 연대 | 작은 굵은 세리프, 흰 글로우, 제목 왼쪽 기준선 정렬 |
| 제목 | 굵은 고딕, 넓은 자간(~0.16em), 하늘색→진청색 그라데이션, 흰 외곽선, 옅은 남색 그림자 |
| 부제 | 보통 굵기 회색 고딕, 흰 글로우 |
